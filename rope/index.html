ロープの回し方

「きれいに回せる人」と「なかなか回せない人」の差は、どこにある？ フリッキーとシャインが、動画を見ながら5つのポイントで学んでいきます。

🤝 まずは基礎：シンクロ

{% include character.html name="shine" position="right" text="2人で回すなら、まずは“シンクロ”から。ほぼ張った状態で、できるだけ小さな力・できるだけゆっくり回すのがコツ。相手（壁）に近づく・離れるをくり返して、合わせる感覚をつかむの。慣れてきたら、両手でそれぞれ円を描いてみて。" %}
{% include character.html name="flekky" position="left" text="なるほど、力いっぱい回さんくていいんや。“小さく・ゆっくり”ね。" %}

✨ きれいに回す5つのポイント

ここからは一人で回すときのフォーム。動画では白い線が「良い軌道」、赤い線が「良くない軌道」で表示されているので、見くらべてみてください。

① 手の軌道は、地面に対して垂直

{% include character.html name="shine" position="right" text="手を動かす“道すじ”が、地面に対してまっすぐ縦になってるのが正解。これが斜めになると、力が横に逃げてロープが暴れちゃう。動画の白い線が良い軌道、赤い斜めがダメな例だよ。" %}
{% include character.html name="flekky" position="left" text="うわ、オレ完全に赤の斜めやったわ…！" %}

② 左右の手で描く円の大きさを、同じに

{% include character.html name="shine" position="right" text="右手と左手で描く円の大きさがバラバラだと、ロープが傾いて回りがゆがむの。左右おなじ大きさの円を意識してみて。" %}

③ 横から見て、ロープの上側が綺麗な弧

{% include character.html name="shine" position="right" text="横から見たとき、ロープの“上側”がなめらかな弧を描いてるのが理想。赤い線みたいにガタガタしてると、跳ぶ人がひっかかりやすくなるんだ。" %}
{% include character.html name="flekky" position="left" text="ふわ〜って弧、これのことか。たしかに気持ちいい。" %}

④ 接地は「点」じゃなく「線（面）」で

{% include character.html name="shine" position="right" text="ロープが地面に当たるとき、一点で“バチンッ”じゃなくて、線（面）でなめらかに接地させるのがコツ。こうすると跳ぶ人が入りやすくなるよ。" %}

⑤ 膝を軽く曲げ、体で回す

{% include character.html name="shine" position="right" text="腕だけで回そうとしないで。膝を軽く曲げて、体ぜんぶを使って回す。とくに遅い曲のときは、ロープをしっかり上まで持ち上げるのが大事だよ。" %}
