## 🎯 第二章: リーダーの一番大事な仕事は「決断」

## 🧭 第三章: ビジョンは "1人で作るもの" じゃない

{% include character.html name="flekky" position="left" text="リーダーって、自分のビジョン示してそこに引っ張っていくイメージなんすけど、unnoさんはどうしてます?" %}

**unno:** 自分の中では、ビジョンって"自分一人で作るもの"ではないと思っています。

{% include character.html name="flekky" position="left" text="えっ、1人で作るんじゃないんすか" %}

**unno:** チームのメンバーがそれぞれ考えていることや、やりたいことをちゃんと聞いて、それをまとめた上で、「じゃあ、チームとしてはここを目指そう」という形にしていました。

**unno:** なので、「これは自分が考えたビジョンです」というより、「みんなの考えがちゃんと入っているビジョンです」という状態を作ることを意識しています。

{% include character.html name="flekky" position="left" text="めっちゃ意外…リーダー=自分の考えで引っ張る、と思ってたっす" %}

---

そして、ビジョンを共有する時に unno が意識している、もうひとつの工夫がある。

**unno:** ビジョンを共有する時は、具体的に個人名を出しながら話すことも大事にしています。

**unno:** 例えば、「これは〇〇がやりたいって言っていたことだよね」とか、「〇〇の考え方って、今のチームに必要だと思うんだよね」というように伝えることで、"自分の考えがちゃんと反映されている""自分の存在を見てもらえている"という感覚を持ってもらえるように意識していました。

{% include character.html name="flekky" position="left" text="個人名出されると、確かに「自分のこと見てくれてんだ」って感じるかも" %}

---

## ⚖️ 第四章: 意見が割れた時、どう着地させるか

{% include character.html name="flekky" position="left" text="でも、いろいろ意見聞いて回ったら、絶対意見割れますよね?そういう時どうしてます?" %}

**unno:** いろんな意見を聞いた上で、最終的には自分が判断していました。

**unno:** ただ、「俺が決めたから従って」ではなく、「みんなの意見は聞いた。その上で、自分はこう判断したから、合わせてもらってもいい?」という言い方をすることが多かったです。

{% include character.html name="flekky" position="left" text="うわ、言い方ひとつで全然違うっすね" %}

**unno:** また、必ずしも多数決で決めるわけではなく、"意見の強さ × 人数"で考えていました。

{% include character.html name="flekky" position="left" text="強さ × 人数…?" %}

**unno:** 例えば、1人だけでも「本当にそれは嫌だ」と強く感じている場合は、そっちを優先することも全然ありました。

{% include character.html name="flekky" position="left" text="多数決の罠、それで外せるのか…" %}

## 🔥 第五章: 「全員同じ熱量」は無理。それでもいい

{% include character.html name="flekky" position="left" text="チームって、全員のモチベが同じくらいだと最強じゃないっすか?それって作れるんすか?" %}

**unno:** 完全に同じ熱量にするのは、不可能だと思っています。

{% include character.html name="flekky" position="left" text="不可能!?" %}

**unno:** ただ、人によってモチベーションの源はかなり違うんですよね。「この人についていきたい」と思って頑張っている人もいれば、「負けたくない」という気持ちで頑張っている人もいる。

**unno:** この"勝ちたい"と"負けたくない"って、似ているようでかなり違うと思っています。

{% include character.html name="flekky" position="left" text="確かに、勝ちにいく時と、負けないようにする時って、なんか動きが違いそう" %}

**unno:** だから、自分は"全員を同じ土俵で測らない"ことが大事だと思っています。

{% include character.html name="flekky" position="left" text="同じ土俵で測らない…熱量フラットにしようとしなくていいのか" %}

## 💬 第六章: 褒める順番と、叱り方

{% include character.html name="flekky" position="left" text="で、メンバーに対するフィードバックって、unnoさんはどうやって配分してます?" %}

**unno:** まず最初に褒めることを大事にしています。

**unno:** 「この人は、自分の良いところをちゃんと見てくれている」と思ってもらった上で、改善点を伝える方が、受け入れてもらいやすいからです。

{% include character.html name="flekky" position="left" text="褒めてから指摘するパターンっすね" %}

**unno:** 一般的には「褒め7割、指摘3割」が良いとも言われますが、ただ褒めるだけでは伝わらないこともあります。

**unno:** なので、自分は「ここが良かった」「これは変えない方がいいと思う」と具体的に伝えつつ、その延長線上で改善点も話すことが多いです。

{% include character.html name="flekky" position="left" text="褒め=抽象的、じゃなくて具体的に褒めるってことか" %}

---

叱る時のルールについても聞いた。

**unno:** 基本的には、"できる限り人前で叱らない"ことを意識しています。

**unno:** ただ、場合によっては人前で伝えた方が良いケースもあるので、そこは使い分けています。

{% include character.html name="flekky" position="left" text="全部1対1ってわけじゃないんすね" %}

**unno:** 特に、会社組織として動くようになってからは、人前で注意する場面も少し増えました。でも、学生チーム時代などは、基本的に人前で叱らないようにしていました。

{% include character.html name="flekky" position="left" text="チームのフェーズで使い分けるんすね" %}

## 💪 エピローグ: リーダーは、決めること

unno のチームマネジメント論は、シンプルで、深かった。

**決断する。** それが、最後にリーダーに残る仕事。

**ビジョンは 1人で作るものじゃない。** メンバーの声を聞いて、まとめて、個人名を出して返す。

**意見の強さは人数じゃない。** 1人の強い嫌悪は、多数の弱い賛成より重い時がある。

**全員同じ熱量にはしない。** 動機の源は人それぞれで、同じ土俵で測らなくていい。

**褒めるは具体的に。** 叱るは、原則人前を避ける。

そして、本当に空気が悪くなった時は、

アイスを買いに行く。

---

これからチームを持つあなたへ。

リーダーは、決めること。
そして、決めた後に「この人の判断なら受け入れよう」と思ってもらえる関係を、日々作り続けること。

その作り方の答えは、unno の言葉の中にいくつも入っていた。
