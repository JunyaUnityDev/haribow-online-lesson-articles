🗺 そもそもロードマップって何？

ロードマップは、あなた専用の「上達の地図」。今どこにいて、次に何をやればいいかが、ひと目でわかるようになっています。

{% include character.html name="shine" position="right" text="ゲームのステージ選択の画面、あるじゃん？あんな感じ。クリアしたマスは埋まって、次に挑戦するマスが光ってる。あなたの現在地がいつでも見えるの。" %} {% include character.html name="flekky" position="left" text="あ〜！じゃあ「次どこ行けばいいっけ？」って迷わなくていいんや。それは助かる…オレすぐ迷子になるタイプやから。" %}

URLは「操作方法」と公式LINEに送ればいつでも届きます。同じURLなら、スマホでもパソコンでも、進み具合はちゃんと引き継がれます。

ゴールは「跳びながら音が取れる」こと。リズムに乗って、自分のステップで自由に踊れる。バトルが組み立てられる。そこまでを、毎日ひとつずつ積み上げていきます。

🎛 どうやって進めるの？（毎日の流れ）

やることは、この5つのくり返しだけです。

{% include character.html name="shine" position="right" text="いくよ〜、メモらなくていいから安心して。" %}
  1. ロードマップを開く（今日やることが出てる。1日 最大3つまででOK）
  2. お手本動画を見る（マスをタップすると技のポイント動画が再生される）
  3. 練習する（1秒でもやったら「練習⭕️」を押して記録。続けた日数がたまる）
  4. できたら動画で提出（公式LINEに、案内される「動画提出：〇〇」のかたちで送る。縄あり／縄なしも指定どおりに）
  5. 合否とフィードバック（HARIBOWが動画を見て「合格／もう一歩」を個別に返信。合格するとロードマップが進む）
{% include character.html name="shine" position="right" text="提出のとき、ひとつだけ——案内された『動画提出：〇〇』の文字（ラベル）はそのまま使ってね。それが合否をひもづける目印になってるの。" %}

提出できる期間は毎月20日〜30日、1か月に最大5本まで。あせらなくて大丈夫、毎月ちゃんと機会があります。

🧭 迷ったら

操作でわからなくなったら、公式LINEに「操作方法」と送れば、提出のしかた・あなたのロードマップURL・退会など、必要な案内がぜんぶ返ってきます。わからないことは、そのままLINEで質問してOKです。
